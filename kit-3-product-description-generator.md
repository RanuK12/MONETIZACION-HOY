# KIT 3: Product Description Generator

## Descripción
Crea descripciones de producto optimizadas para conversión en 2 minutos. Copy que vende.

## Instrucciones (Copy-Paste Ready)

### Paso 1: Reúne info básica
Ten a mano:
- Qué es tu producto exactamente
- Qué problema resuelve
- Para quién es
- Precio aproximado
- 1-2 ejemplos de cómo se usa

### Paso 2: Copia este prompt

```
Eres copywriter especialista en productos digitales.
Necesito una descripción de producto que VENDA.

INFORMACIÓN DEL PRODUCTO:
- Nombre: [TU PRODUCTO]
- Qué es: [DESCRIPCIÓN BREVE]
- Problema que resuelve: [PROBLEMA]
- Para quién: [TU CLIENTE IDEAL]
- Precio: [RANGO DE PRECIO]
- Beneficio #1: [BENEFICIO PRINCIPAL]
- Beneficio #2: [BENEFICIO 2]
- Beneficio #3: [BENEFICIO 3]
- Ejemplo de uso: [CÓMO SE USA]

CREA:
1. Headline (máx 10 palabras, debe hacer click)
2. Subtítulo (30-40 palabras, amplía el hook)
3. Descripción corta (50-70 palabras, enfocada en beneficios)
4. Descripción media (150-200 palabras, incluye features + benefits)
5. Descripción larga (300-400 palabras, completa, incluyendo FAQ mental)
6. Bullet points (5 beneficios principales, máx 15 palabras cada uno)
7. Call-to-Action (3 opciones: urgencia, curiosidad, riesgo reverso)

Tono: [profesional/casual/entusiasta]
Estilo: [vendedor/consultor/amigo]
```

### Paso 3: Ejecuta en ChatGPT/Claude
Pega el prompt completo. Obtendrás 7 versiones de copy.

### Paso 4: Elige la que mejor se ajuste
- Headline: usa en Gumroad
- Descripción media: usa en Twitter/marketing
- Descripción larga: usa en landing page
- Bullets: usa en redes sociales

## Prompts Pre-Hechos (Copy-Paste Directo)

### Template Para Kit de Automatización:

```
Eres experto en venta de productos digitales.
Un creador vende un KIT de AUTOMATIZACIÓN en Gumroad.

DETALLES:
- Producto: Kit de Automatización [TU NOMBRE]
- Qué incluye: Scripts, prompts, guías paso a paso
- Para: Emprendedores/freelancers que quieren ahorrar tiempo
- Tiempo ahorro: 10+ horas semanales
- Precio: $17-47 USD

CREA COPY CONVINCENTE:
1. Headline (hook emocional o problema)
2. 3 beneficios principales (máx 15 palabras cada uno)
3. Descripción vendedora (100 palabras)
4. FAQ: "¿Para quién es?" "¿Qué necesito?" "¿Se puede usar si soy..."?
5. Garantía/promesa (por qué confiar)
6. CTA final (urgencia)
```

### Template Para Servicio/Consultoría:

```
Copywriter mode: ON.
Escribo copy para vender servicio de [TU SERVICIO].

DATOS:
- Servicio: [NOMBRE]
- Resultado: [QUÉ CONSIGUE EL CLIENTE]
- Tiempo: [CUÁNTO TARDA]
- Inversión: [PRECIO]
- Ideal para: [TIPO DE CLIENTE]
- Garantía: [QUÉ PASA SI NO FUNCIONA]

REDACTA:
1. Headline que dispare curiosidad
2. Problema específico que resuelvo
3. Por qué yo (diferencial)
4. Pasos del proceso
5. Testimonios mentales (qué dirán después)
6. CTA con urgencia
```

### Template Rápido (Si tienes prisa):

```
Resumen rápido de mi producto:
[INSERTA EN 3 ORACIONES QUÉ ES]

Crea:
- Headline vendedor (máx 10 palabras)
- Descripción que convenza en 2 segundos (30 palabras)
- Porqué deberían comprarlo (2 razones)
- Precio recomendado
```

## Checklist de Copy Ganador

Tu descripción debe tener:

✅ Headline que para al scroll
✅ Beneficio #1 en primeras 10 palabras
✅ Lenguaje específico (no genérico)
✅ Dirigido a 1 persona (no a todos)
✅ Números cuando es posible (10x, 50%, etc)
✅ Pregunta o curiosidad (hook)
✅ Sociedad prueba (testimonios/casos)
✅ Objeción rebatida (¿problemas? Responde)
✅ CTA clara (botón, enlace, acción)
✅ Urgencia mínima (limitado, tiempo, etc)

## Integración en Plataformas

### Para Gumroad:
- Title: headline
- Product description: versión media/larga
- Product type: "digital"
- License: "personal use"

### Para Twitter:
- Tweet 1: Headline + link
- Tweet 2: Beneficio #1 + prueba social
- Tweet 3: "Aquí está el link" + urgencia

### Para Email:
- Subject: Headline
- Body: Descripción corta + bullets
- CTA: botón de compra

## Resultados Esperados
- Mes 1: conversión inicial (1-3% si es buen producto)
- Mes 2: conversión optimizada (3-7%)
- Mes 3: copy probado, lista para escalar (5-10%)

## Bonus: A/B Test

Crea 2 versiones de copy:
- Versión A: Enfoque en Problema ("¿Cansado de...?")
- Versión B: Enfoque en Resultado ("Consigue...")

Publica ambas, ve cuál convierte más, usa esa.
