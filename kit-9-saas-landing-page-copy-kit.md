# SaaS Landing Page Copy Kit
## The Copy System That Converts Visitors Into Trials

---

## THE PROBLEM WITH MOST SAAS LANDING PAGES

Most SaaS landing pages fail because they describe features instead of solving problems.

Visitors don't want to know what your software does.
They want to know what their life looks like after using it.

This kit gives you the exact copy frameworks, headline formulas, and section templates used by the highest-converting SaaS landing pages.

---

## PART 1: THE LANDING PAGE FRAMEWORK (CONVERT Structure)

**C — Capture** (Hero Section)
**O — Obstacle** (Problem Section)
**N — New Way** (Solution Section)
**V — Validate** (Social Proof)
**E — Expand** (Features/Benefits)
**R — Remove Risk** (Objection Handling + FAQ)
**T — Take Action** (CTA)

## PART 2: 30 HEADLINE FORMULAS

### Pain-Focused Headlines
1. "Stop [painful activity]. Start [desired outcome]."
2. "The [job title] who [frustrating problem] — this is for you."
3. "Finally, a way to [desired outcome] without [common frustration]."
4. "Why are you still [painful old way]?"
5. "[Number] hours lost to [problem] every week. Fix it in 5 minutes."

### Outcome-Focused Headlines
6. "[Specific result] in [specific timeframe]. Guaranteed."
7. "The fastest way to [desirable outcome] for [target audience]."
8. "Turn [raw input] into [valuable output] automatically."
9. "[Target audience] use [Product] to [achieve specific result]."
10. "Go from [current state] to [desired state] in [time]."

### Credibility Headlines
11. "[Number] [companies/teams/users] already use [Product] to [result]."
12. "Trusted by [Company Type] at [Company A], [Company B], [Company C]."
13. "The [category] platform that [specific companies] rely on."
14. "[Award/metric] — [Product] is the [superlative] way to [outcome]."
15. "Join [number]+ [target audience] who [achieve result] with [Product]."

### Curiosity Headlines
16. "What if [desirable scenario] was actually possible?"
17. "The [job title]'s secret to [impressive result]."
18. "We [bold claim]. Here's how."
19. "Everyone [does it the old way]. We built a better one."
20. "Your [competitor] is using this. Are you?"

### Direct & Simple Headlines
21. "[Verb] your [noun] with AI."
22. "[Product]: [One-line value proposition]."
23. "The [simplest description] for [target user]."
24. "[Do thing] without [bad thing]."
25. "Less [pain]. More [gain]. [Product]."

### Question Headlines
26. "Tired of [specific frustration]?"
27. "How much is [problem] costing you?"
28. "What would you do with [X hours/dollars] back every week?"
29. "Ready to [achieve goal] — without [obstacle]?"
30. "Is your [tool/process] actually working?"

## PART 3: COMPLETE SECTION TEMPLATES

### HERO SECTION

**Formula:**
```
[Headline — outcome or problem]
[Subheadline — who it's for + how it works in 1 sentence]
[Primary CTA button] + [Secondary CTA or trust signal]
[Hero image/screenshot showing product in action]
```

**Example:**
```
Headline: Turn customer feedback into product decisions in minutes.
Sub: [Product] reads your support tickets, reviews, and surveys — 
     then tells you exactly what to build next.
CTA: [Start Free Trial] — No credit card required
Trust: "Loved by 2,400+ product teams"
```

**Template — 5 Hero variants:**

Variant A (Pain):
```
[Frustrating thing] is killing your [metric].
[Product] fixes it automatically.
[CTA] — Free for [X] days
```

Variant B (Outcome):
```
[Specific result] for [target user].
Used by [social proof number] teams at [name-drop companies].
[CTA] — [Risk reducer]
```

Variant C (Speed):
```
[Goal] in [surprisingly short time].
No [common blocker]. No [common blocker]. Just [simple thing].
[CTA]
```

Variant D (Contrast):
```
Other [tools] [do thing the old way].
[Product] [does thing the new way].
[CTA] — [Time to value]
```

Variant E (Question):
```
What if [desirable scenario]?
[Product] makes it possible — in [timeframe].
[CTA]
```

### PROBLEM SECTION

**Formula:**
```
"You know the feeling..."
[3 specific pain points written as experiences, not features]
"There has to be a better way."
```

**Template:**
```
If you're like most [target user], you've experienced this:

- [Painful scenario 1 — specific, emotional]
- [Painful scenario 2 — specific, emotional]  
- [Painful scenario 3 — specific, emotional]

You've tried [common solution 1] and [common solution 2].
They helped — but not enough.

[Product] was built for exactly this.
```

### SOLUTION SECTION ("How It Works")

**Formula — 3 steps max:**
```
Step 1: [Simple action verb] your [input]
Step 2: [Product] [does the magic]
Step 3: You get [specific output/result]
```

**Template:**
```
[Product] works in 3 steps:

1. [Action] — [one sentence on what user does]
2. [Action] — [one sentence on what product does automatically]
3. [Action] — [one sentence on the outcome/result]

From [start state] to [end state] in [time].
```

### SOCIAL PROOF SECTION

**Formula:**
```
[Number] stat + [Number] stat + [Number] stat
[3 testimonials — each covers: who, what result, specific metric]
[Logo strip of recognizable companies]
```

**Testimonial template:**
```
"[Specific result with metric]. We [used to do X] — 
now we [do better thing] with [Product]."

— [First Name Last Name], [Title] at [Company]
```

**Strong testimonial checklist:**
- Mentions a specific metric or number
- Describes before/after
- Comes from a recognizable title (Head of, VP, Founder)
- Is 1-3 sentences (not an essay)

### FEATURES/BENEFITS SECTION

**Rule:** For every feature, write the benefit. For every benefit, write the emotion.

**Template:**
```
Feature: [What it does technically]
Benefit: So you can [specific outcome]
Emotion: Which means [feeling/freedom/relief]
```

**Section format:**
```
[Feature name] — [One-line benefit]
[2-sentence expansion of value]
[Optional: metric, proof point, or mini testimonial]
```

**10 Feature-to-Benefit conversions:**

| Feature | Benefit Copy |
|---|---|
| AI-powered | "Works automatically — no manual setup" |
| Real-time sync | "Your team always sees the same thing" |
| One-click export | "From [Product] to [destination] in seconds" |
| Custom templates | "Start fast. Look professional from day one." |
| API integration | "Fits into your existing stack — no disruption" |
| Analytics dashboard | "Know what's working before your next meeting" |
| Role-based access | "Everyone sees what they should. Nothing more." |
| Automated reports | "Reports write themselves. You just present." |
| Mobile app | "Check in from anywhere. Close the loop faster." |
| White-label option | "Your brand. Your clients. Full control." |

### PRICING SECTION

**Formula:**
```
[Plan name — evocative, not generic]
[Who it's for — 1 sentence]
[Price + billing period]
[3-5 bullet benefits — not features]
[CTA]
```

**Pricing section copy principles:**
1. Name plans after outcomes, not sizes (Starter/Growth/Scale > Basic/Pro/Enterprise)
2. Highlight the middle plan with "Most Popular" badge
3. Anchor high — list highest plan first (optional)
4. Reduce friction: "No credit card required" / "Cancel anytime"
5. Add a comparison table if you have 3+ plans

**Template:**
```
STARTER — $[X]/mo
For [specific user type] getting started with [problem].
- [Benefit 1]
- [Benefit 2]
- Up to [limit]
[Start Free Trial]

GROWTH — $[X]/mo ← Most Popular
For [specific user type] who need [more of thing].
- Everything in Starter
- [Key differentiating benefit]
- [Key differentiating benefit]
- Priority support
[Start Free Trial]

SCALE — $[X]/mo
For [teams/companies] with [advanced need].
- Everything in Growth
- [Enterprise benefit]
- Dedicated account manager
- SLA guarantee
[Contact Sales]

All plans include a 14-day free trial. No credit card required.
```

### FAQ SECTION (Objection Handling)

**The 8 questions every SaaS FAQ must answer:**

1. "How long does setup take?"
   → "You'll be up and running in under [X minutes]. No [technical thing] required."

2. "Do I need to [technical prerequisite]?"
   → "No. [Product] works out of the box. All you need is [low bar]."

3. "What happens to my data?"
   → "Your data is [encrypted/private/yours]. We [specific security measure]. [Compliance certification if applicable]."

4. "Can I cancel anytime?"
   → "Yes. Cancel in 2 clicks, no questions asked. You keep your data for 30 days."

5. "How is this different from [top competitor]?"
   → "[Product] is built for [specific user] who needs [specific thing]. [Competitor] is better for [different use case]. We're better for [your ideal customer]."

6. "Is there a free trial?"
   → "[X]-day free trial, no credit card. You'll have access to [key features]."

7. "What if I need help?"
   → "[Support channel] support available [hours]. Avg. response time: [X minutes/hours]."

8. "What integrations do you support?"
   → "We integrate with [top 5 tools your target audience uses]. Full list: [link]"

## PART 4: COPY EDITING CHECKLIST

Before publishing, check every line against this:

**Clarity**
- [ ] Can a 10-year-old understand this sentence?
- [ ] Is there any jargon that needs removing?
- [ ] Does every section have one clear point?

**Specificity**
- [ ] Replace "fast" with a number: "3x faster", "in 5 minutes"
- [ ] Replace "easy" with a description: "no code required", "3 clicks"
- [ ] Replace "powerful" with a result: "handles 10,000 requests/sec"

**Voice**
- [ ] Is it speaking to one person, not a group?
- [ ] Does it use "you" more than "we"?
- [ ] Does it sound human, not corporate?

**Conversion**
- [ ] Is there one main CTA per section?
- [ ] Does every objection have an answer somewhere on the page?
- [ ] Is the value clear before the price appears?

## PART 5: AI PROMPTS FOR LANDING PAGE COPY

### Prompt 1: Generate hero section
```
My SaaS product is [description]. Target user: [job title/type]. 
Main problem it solves: [problem]. Main outcome: [result].
Write 5 hero headline variations using these formulas:
pain-focused, outcome-focused, speed-focused, curiosity, direct.
Include a subheadline for each.
```

### Prompt 2: Write problem section
```
My target user is [description]. Their 3 biggest frustrations with 
[current solution/status quo] are [pain 1], [pain 2], [pain 3].
Write a problem section for my landing page that makes them feel 
deeply understood. Use second-person "you". 100 words max.
```

### Prompt 3: Feature to benefit copy
```
My SaaS has these features: [list features].
For each feature, write the benefit (what the user can do/feel) 
and the emotion (what freedom or relief it gives them).
Format: Feature → Benefit → Emotional payoff.
```

### Prompt 4: Generate testimonials framework
```
I need to collect testimonials from my users for my SaaS landing page.
Write 5 questions I should ask customers to elicit powerful, 
specific, metric-driven testimonials.
```

### Prompt 5: Rewrite weak copy
```
This is a section from my SaaS landing page: [paste copy]
It's too vague and feature-focused. Rewrite it to be:
- Benefit-focused (not feature-focused)
- Specific (add placeholders for metrics/numbers)
- Emotionally resonant
- Under [X] words
```
