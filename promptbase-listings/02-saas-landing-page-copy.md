## Description
Generate complete, high-converting landing page copy for any SaaS product in under 2 minutes. Based on proven copywriting frameworks (PAS, AIDA, StoryBrand) adapted specifically for software products. Outputs ready-to-paste sections: hero, features, social proof, pricing, FAQ, and CTA.

## The Prompt

```
You are a world-class SaaS copywriter who has written landing pages for products that generated $10M+ ARR. You combine direct response copywriting (Gary Halbert, Eugene Schwartz) with modern SaaS best practices (Stripe, Linear, Vercel style).

PRODUCT: {product_name}
ONE-LINE: {what_it_does_in_one_sentence}
TARGET AUDIENCE: {who_uses_it}
MAIN PAIN POINT: {biggest_problem_it_solves}
KEY DIFFERENTIATOR: {why_this_over_alternatives}
PRICE POINT: {pricing_model}
TONE: {professional/playful/technical/minimal}

Generate a COMPLETE landing page with these sections:

1. HERO SECTION
- Headline (max 8 words, benefit-driven, no jargon)
- Subheadline (1 sentence expanding on the headline)
- CTA button text (action verb + outcome)
- Social proof micro-line ("Trusted by X teams" or "Y users saved Z hours")

2. PROBLEM SECTION (3 pain points)
- Each: emoji + bold statement + 1-line expansion
- Use "you" language, mirror how the audience describes the pain

3. SOLUTION SECTION
- Transition line from problem to solution
- 3 key features, each with: icon suggestion, title (3 words max), description (2 lines), micro-benefit

4. HOW IT WORKS (3 steps)
- Step number + action verb title + 1 sentence + suggested screenshot/visual description

5. SOCIAL PROOF
- 3 testimonial templates (role + company size + specific result + quote style)
- Logos section suggestion
- Metric callouts (3 numbers that impress)

6. PRICING SECTION
- Pricing table copy for {number_of_tiers: 2/3} tiers
- Each tier: name, tagline, price display, 5-7 features, CTA text
- Highlight recommended tier

7. FAQ (5 questions)
- Objection-handling questions with concise, confident answers
- Include: pricing, security, migration, support, comparison to alternatives

8. FINAL CTA
- Urgency-driven headline
- Risk-reversal statement
- Button text + supporting micro-copy

FORMAT: Output as markdown with clear section headers. Each section should be copy-paste ready into any website builder (Framer, Webflow, WordPress).
```
