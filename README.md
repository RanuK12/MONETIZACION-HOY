## 🎓 Aprendizajes Clave

1. **Velocidad > Perfección**
   - Lanzar en 1 hora es mejor que "perfeccionar" por 2 semanas

2. **Copy > Producto**
   - Mejor descripción = más ventas
   - Cambia copy si no convierte

3. **Data > Opinión**
   - Sigue lo que vende, ignore lo demás

4. **Responde Rápido**
   - Comentario en primeras 2h = 3x más conversión

5. **Escala Lentamente**
   - Valida con 10 clientes antes de escalar
